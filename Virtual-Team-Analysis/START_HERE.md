# 🚀 START HERE — Safahati Non-Technical User Features

**Welcome!** This is your entry point to a complete product specification for 14 non-technical user features on the Safahati website platform.

---

## ⏱️ 30-Second Summary

Safahati is building a website platform for non-technical users in Saudi Arabia. The analysis documents 14 new features specifically designed for users who don't know what "section" or "template" means.

**Key features:**
- 5-minute wizard to build a site automatically
- WhatsApp integration (MENA-first)
- AI copy generation in Arabic + English
- Live preview, auto-save, undo
- Mobile admin app

**Status:** Fully specified. Ready to code. Sprint 1 starts now.
